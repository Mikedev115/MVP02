# นุ่มดี Hair Sleep Spa — ระบบจัดการร้านสระผมและหัวสปา (MVP เดโม)

เว็บแอปฝั่ง frontend อย่างเดียวสำหรับสาธิตให้เจ้าของร้านสระผม/Head Spa เห็นภาพการจัดการการจอง ลูกค้า งานประจำวัน และการวิเคราะห์ธุรกิจในที่เดียว
**ข้อมูลทั้งหมดเป็นข้อมูลสมมติ เก็บในหน่วยความจำของเบราว์เซอร์ การเปลี่ยนแปลงจะหายเมื่อรีเฟรชหน้า** (มีปุ่ม "รีเซ็ตข้อมูลเดโม")

## เริ่มใช้งาน

```bash
npm install
npm run dev        # เปิดเว็บสำหรับพัฒนา
npm test           # unit test ของตรรกะธุรกิจ
npm run build      # ตรวจชนิดข้อมูล (tsc) + build สำหรับ deploy
```

Deploy บน Vercel ได้ทันที (Vite preset) — `vercel.json` มี rewrite สำหรับ SPA routing แล้ว ไม่มี backend/ฐานข้อมูล/API ภายนอก

## โมดูล

| เมนู | สิ่งที่ทำได้ |
| --- | --- |
| ภาพรวม | KPI, แนวโน้มรายได้/การจอง (เปลี่ยนช่วงเวลาได้), บริการยอดนิยม, ช่องทางลูกค้า, ลูกค้าใหม่/ประจำ, ใช้เวลาพนักงาน/ห้อง, คิวที่กำลังจะถึง, ข้อเสนอแนะ, แจ้งเตือน — คลิก KPI/กราฟเพื่อดูรายการที่กรองแล้ว |
| การจอง | มุมมองรายวัน/รายสัปดาห์/รายการ, สร้าง แก้ไข เลื่อนนัด ยกเลิก ยืนยัน ปิดงาน, ตรวจคิวซ้อนของพนักงาน/ห้อง/ลูกค้า, ไกด์เดโมจองตั้งแต่ต้นจนจบ |
| ลูกค้า | ค้นหา/กรองกลุ่ม (ใหม่ ประจำ ห่างหาย), โปรไฟล์ ประวัติ ยอดใช้จ่าย ความถี่ บริการที่ชอบ, เพิ่ม/แก้ไขลูกค้า |
| การตลาดและลูกค้า | ช่องทางที่ลูกค้ารู้จักร้าน, ช่วงอายุ, ใหม่ vs เดิม, ขั้นตอนจองถึงใช้บริการ, วัน/ชั่วโมงยอดนิยม + heatmap, รายได้ตามหมวด, retention, กลุ่มลูกค้า, ค่าโฆษณาตัวอย่าง |
| งานประจำวัน | **เตียงว่างและข้อความโพสต์คิวว่าง (Facebook/LINE/TikTok)**, คิวรอยืนยัน, ลูกค้าที่กำลังมา, เช็กลิสต์เปิด-ปิดร้าน, สถานะงาน, ช่างและเตียง ณ ตอนนี้, สรุปประจำวัน |
| ข้อมูลเชิงลึก | ข้อเสนอแนะจากกฎคำนวณ (ไม่ใช่ AI) พร้อมตัวเลขประกอบและสิ่งที่ควรทำ |

## โครงสร้างโค้ด

```
src/
  types.ts            ชนิดข้อมูลทั้งหมด
  data/               catalog (บริการ ช่าง เตียง ฯลฯ) + seed.ts (สร้างข้อมูลสมมติแบบ deterministic)
  state/              store.tsx (ข้อมูลหลัก + actions), ui.tsx (ช่วงวันที่, toast, ไกด์)
  lib/                date, format, conflicts (ตรวจคิวซ้อน), metrics (ตัวเลขที่คำนวณ), insights, links
  components/         ui/ (ส่วนประกอบใช้ซ้ำ), layout/ (AppShell, DateRangePicker)
  features/           dashboard, bookings, customers, marketing, operations, insights
```

หลักการ: ตัวเลขทุกตัวคำนวณจาก `AppData` (customers, appointments, tasks) ชุดเดียว ไม่มี KPI ที่กำหนดค่าตายตัว
